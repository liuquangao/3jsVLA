# SO-101 robot asset

This directory contains the official SO-101 new-calibration URDF and the 13 STL files referenced by it.

- Source: https://github.com/TheRobotStudio/SO-ARM100/tree/main/Simulation/SO101
- LeRobot mirror: https://huggingface.co/buckets/lerobot/robot-urdfs/tree/so101
- License: Apache License 2.0 (see `LICENSE`)
- URDF SHA-256: `3a65d2d35e68a8d2f0c2cc176d19b884506543c93ba72980145b80abe276022c`

The URDF uses the new calibration convention: the virtual zero of each arm joint is the middle of its range.
